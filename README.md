# Telematics Board: CAN Gateway with 4G Modem (MSc Project)

Hardware design from my MSc in Electrical Engineering at Szechenyi Istvan University, designed in Altium Designer.
A wide-input-voltage board that connects a CAN bus to a cellular (4G)
modem, controlled by a dsPIC33CH microcontroller.

<img width="806" height="778" alt="image" src="https://github.com/user-attachments/assets/82e980e4-2a81-4a8c-b268-4e701f6c63ef" />

## Features
- 3.5 A buck regulator for a wide-range supply input
- dsPIC33CH64MP505 dual-core DSC with ICSP programming
- CAN interface (SN65HVD230Q-Q1) with TVS bus protection
- 4G modem interface with micro-SIM, UART and control lines
- 4-layer board with RFI shielding and adhesive antenna
